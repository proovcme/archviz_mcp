# Типовые ошибки архитектурных визуализаций

Это наблюдения из рабочего процесса, не статистическое исследование качества генераторов.

| Наблюдавшаяся ошибка | Решение для следующей работы |
|---|---|
| Двери и ручки меняются между видами | Общий тип/материал двери в модели, сверка одинакового проёма в серии |
| Под балконом исчезают входы; стена становится наклонной | Установить приоритет плана/модели и явно записать согласованные допущения |
| Кабинки входят в стены | Проверить положение и габариты в общей сцене до генерации |
| На одном рабочем месте исчезает перегородка или оборудование | Проверять комплектность отдельных мест, а не только общую атмосферу |
| Потолок по одному описанию получает разные панели в каждом кадре | Смоделировать единые панели и светильники, сохранить камеры |
| После нескольких правок изображения теряют геометрию | Возвращаться к свежему кадру модели |
| «Красиво» превращается в пустой стерильный интерьер | Задать конкретные действия людей и умеренные бытовые детали |
| Появляются лишние короба/световые ниши | Сверять горизонтальные поверхности и уровни с моделью |
| Служебные линии BIM остаются на стекле | Убирать аннотации на исходном виде или явно исключать при обработке |
| Нет розеток, датчиков и выключателей | Включить видимые функциональные детали в проверку; не считать их изображение инженерным проектом |
| Серия похожа по палитре, но выглядит синтетически | Проверять фотографическую убедительность каждого кадра отдельно от геометрии и цвета |
| Один кадр принят, остальные ошибочно объявлены удачными | Сохранить решения по конкретным версиям; после принятого пилота проверять каждый выбранный ракурс |
| Правка геометрии уничтожила удачную подачу | Сохранить принятую версию и область одобрения; новую версию сравнить по двум осям |
| Аксонометрический исходник ведёт к «макету» вместо снимка | Выбрать подходящую проекту камеру до генерации; не считать высоту человека универсальным стилем |
| Зелёная автоматическая проверка принята за доказательство фотореализма | Контракт контролирует записи/ревизии; качество требует просмотра пикселей и пользовательской оценки |

Палитра, материалы, характер потолка и оформление альбома задаются для текущего проекта. Не превращай частный выбор заказчика в универсальные правила и не переноси его в другой проект без основания.
