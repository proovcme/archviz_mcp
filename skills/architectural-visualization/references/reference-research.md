# Подбор и разбор референсов онлайн

## Источники и хранение

MCP работает с OfficeNext, ArchDaily, FRAME, Architizer и WAF. Возможности различаются; проверь `reference_sources` вместо предположения, что у всех есть серверный поиск. Нет API-ключа, локальной базы, краулера или архива картинок. HTML-кэш — до 16 страниц в RAM на 180 секунд. Выбранное изображение возвращается в память хоста до 1600 px; файл не создаётся.

- OfficeNext: нативный поиск и карточки; русские ключевые слова.
- ArchDaily: чтение публичных карточек и галерей; поиск хостом по домену. Не обходи подписку ради статьи.
- FRAME: публичные `/project/`, описание, авторство, фото и планы; поиск хостом. Статус shortlisted не означает победу.
- Architizer: поиск Journal по английским словам; статьи могут включать много проектов. Отдельно `browse_reference_catalog(source="architizer", year=...)` для A+Awards. Запрашиваются выпуски 2013–2026; доступность конкретного года проверяется вызовом. Для чтения/картинки конкурса передавай `entry_id` вместе с URL каталога.
- WAF / Interiors: каталог 2025, победители, бюро и конкурсные планшеты. Планшет не называй фотографией; закрытая подробная карточка не считается прочитанной.
- Office Snapshots и Dezeen: веб-поиск/браузер хоста; прямые серверные адаптеры не подключены.

## Исследование

1. Выдели тип пространства, ограничения модели и конкретную задачу дизайна.
2. При широком запросе используй несколько площадок: OfficeNext с русскими словами и `search_references(source="all", query="...")` с короткими английскими запросами. Для вестибюля: lobby, acoustic, ceiling; для рабочих зон: workplace, office. Автоматического перевода нет.
3. Проверь `source_reports`: различай выполненную выдачу, ошибку, нулевой результат и `host_search_required`. Последний ответ требует настоящего веб-поиска по предложенному домену. Не выдавай подсказку за найденный проект.
4. Для исторического обзора выбери годы и фильтры каталога явно. Пагинация каталога — `offset`/`next_offset`, OfficeNext — `page`; Journal пока только первая страница. Не выполняй массовый обход без задания. Нулевая выборка не доказывает отсутствие решения во всех годах.
5. Прочитай карточки и просмотри сами фото, планы и обратные ракурсы. Не подменяй фотогалерею рекламой, рекомендациями соседних проектов или изображениями других конкурсантов.
6. Верни небольшую подборку с авторами, ссылками, конкретными применимыми приёмами и ограничениями. Редакционная публикация, участие, шорт-лист и разные виды побед — разные статусы. Покажи разные подходы, если задача предполагает выбор; не добирай нерелевантные примеры ради количества.

При недоступности или изменении сайта используй доступный поиск/браузер хоста по официальному домену. Не обходи защиту, не имитируй результаты и не называй сведения из памяти живой выдачей.

## Карточка рекомендации
- Проект, автор, ссылка, источник, дата проверки.
- Даты реализации / публикации / премии раздельно, если они указаны.
- Задача нашего проекта.
- Подтверждённое описание решения автора.
- Что видно на конкретных фотографиях (ссылка/индекс).
- Предлагаемый перенос в нашу модель, его ограничения.
- Неизвестное: бюджет, размеры, акустические свойства, узлы, обслуживание.
- Оценка пользователя: только его собственное высказывание, с областью действия.

Материалы, бюджет и показатели называй подтверждёнными лишь со ссылкой на соответствующий текст/документ. Историческую цену сохраняй с годом и составом работ; не пересчитывай её в текущую смету по фотографии. Указанное в конкурсе ограничение стоимости не равно фактической стоимости конкретного объекта.

## Сохранение выбора
При запросе на сохранение используй небольшой файл в текущем проекте, например «Выбранные_референсы.json». Поля: title, project_url, image_urls, architect, checked_at, use_for, observed, proposed_transfer, unknowns, user_feedback, scope. Не сохраняй полный текст страниц, изображения или все результаты поиска. Обновляй существующий выбор, избегая дублей.

Папка с ссылками остаётся подборкой конкретного проекта, а не скрытой базой всего каталога. Для нового проекта не переноси запреты и предпочтения предыдущего заказчика автоматически.
