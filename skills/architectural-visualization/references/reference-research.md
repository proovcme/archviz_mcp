# Подбор и разбор референсов онлайн

## Границы пилота
MCP читает публичный OfficeNext: карточки проектов, нативный поиск и галереи. Нет API-ключа, локальной базы, краулера или архива картинок. HTML-кэш — не более 16 страниц в RAM на 180 секунд. Фотография загружается только по запросу и возвращается в память хоста с уменьшением до 1600 px; файл не создаётся.

Поиск выполняется на одной странице нативной смешанной выдачи; сервер отбирает только карточки проектов. Он не является семантическим поиском по всему архиву. Параметр page переключает страницы; отсутствие результатов на одной странице не означает отсутствие подходящих проектов вообще.

## Исследование
1. Выдели тип пространства, геометрические ограничения, задачу дизайна и требования эксплуатации.
2. Ищи короткими русскими запросами; при нуле результатов попробуй синоним или одно слово. Не делай многолетний обход каталога без отдельного задания.
3. Прочитай несколько подходящих карточек. Для focus полезны корни: «акуст», «потол», «вестиб», «кабинет», «освещ».
4. Просмотри релевантные фото; при необходимости план и обратный ракурс того же проекта. Наличие ссылки или миниатюры не равно визуальному анализу.
5. Верни небольшую обоснованную подборку с прямыми ссылками и авторами. Не заполняй результат заведомо неподходящими проектами ради количества.

Если сайт недоступен, поменял разметку или результатов мало, используй обычный поиск вида site:officenext.ru/projects/ и браузер. Не имитируй работу недоступного MCP и не называй результаты из памяти живой выдачей.

## Другие источники
- OfficeNext — https://www.officenext.ru/projects/ ; офисы и общественные интерьеры.
- WAF / WAF Interiors — https://www.worldarchitecturefestival.com/ ; здания, общественные пространства, интерьеры.
- ArchDaily Building of the Year — https://boty.archdaily.com/ ; реализованные здания и интерьеры.
Проверяй актуальные разделы и годы онлайн. Внешние источники пока доступны через инструменты веб-поиска хоста, а не через адаптер OfficeNext. Победа, номинация, участие и редакционная публикация — разные статусы.

## Карточка рекомендации
- Проект, автор, ссылка, источник, дата проверки.
- Даты реализации / публикации / премии раздельно, если они указаны.
- Задача нашего проекта.
- Подтверждённое описание решения автора.
- Что видно на конкретных фотографиях (ссылка/индекс).
- Предлагаемый перенос в нашу модель, его ограничения.
- Неизвестное: бюджет, размеры, акустические свойства, узлы, обслуживание.
- Оценка пользователя: только его собственное высказывание, с областью действия.

Материалы, бюджет и показатели называй подтверждёнными лишь со ссылкой на соответствующий текст/документ. Историческую цену сохраняй с годом и составом работ; не пересчитывай её в текущую смету по фотографии. Указанное в конкурсе ограничение стоимости не равно фактической стоимости конкретного объекта.

## Сохранение выбора
При запросе на сохранение используй небольшой файл в текущем проекте, например «Выбранные_референсы.json». Поля: title, project_url, image_urls, architect, checked_at, use_for, observed, proposed_transfer, unknowns, user_feedback, scope. Не сохраняй полный текст страниц, изображения или все результаты поиска. Обновляй существующий выбор, избегая дублей.

Папка с ссылками остаётся подборкой конкретного проекта, а не скрытой базой всего каталога. Для нового проекта не переноси запреты и предпочтения предыдущего заказчика автоматически.
