# Проверка дополнительных источников

Дата: 31 октября 2026. Это выборочная проверка доступности публичных страниц и структуры данных, не обзор всех проектов и не список уже работающих адаптеров. В MCP реализован только OfficeNext.

Метод: поиск по официальным доменам, переходы из списков премий к проектам, обычные HTTP GET без обхода защиты, сравнение с результатами веб-инструмента. Тексты и фотографии не архивировались. Наличие URL изображения не означает просмотра пикселей или проверки его применимости к проекту. Успешный HTTP 200 не доказывает полноту карточки.

## Приоритеты

Для практических офисных решений — Office Snapshots и OfficeNext. Для интерьеров и экстерьеров более широкого круга — ArchDaily. Для отбора по премиям — WAF, FRAME и Architizer, с сохранением различия между участием, шорт-листом и победой.

Первый кандидат на новый полноценный адаптер — ArchDaily. Галереи WAF/Architizer можно реализовать отдельно как поиск по наградам; это не даст автоматически доступ ко всем фотографиям и описаниям проектов. До выпуска каждого адаптера нужны проверки поиска, карточки, атрибуции и просмотра одного изображения через настоящий MCP-клиент.

Наблюдаемые HTTP-коды относятся к дате, среде и конкретным URL проверки. Они не означают постоянную недоступность сайта для всех пользователей. Веб-поиск может возвращать индексированную копию, даже когда прямой серверный запрос блокируется.
