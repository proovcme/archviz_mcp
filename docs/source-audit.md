# Проверка источников версии 0.3

Проверено 31 октября 2026. Это выборочная проверка конкретных страниц и операций, не гарантия доступности всего сайта и не обзор художественного качества. Контент проектов и фотографии на диск не сохранялись.

Метод: обычный HTTPS, разбор публичных данных выбранной страницы, проверка через настоящий stdio MCP. Нет обхода защиты, входа в аккаунты или скрытых API. Ссылка на изображение не означает визуального анализа; декодирование проверяет передачу, а не применимость дизайна.

## Источники только через хост

- **Office Snapshots**: [PopiPlay](https://officesnapshots.com/2026/09/30/popiplay-offices-belgrade/) и [акустические панели](https://officesnapshots.com/photos/?tag=acoustic-panel) читаются веб-инструментом; прямой HTTP вернул 403. Полезен для рабочих мест и деталей, но серверный адаптер не заявлен.
- **Dezeen Awards**: [премия](https://www.dezeen.com/awards/) вернула защитную страницу 403. Доступность архива не подтверждена.
- **Исторические WAF**: [страница брошюр](https://worldarchitecturefestival.com/WAF2026/en/page/winners-brochures) содержит ссылки на 2025, 2024, 2023, 2022, 2021/2020. Содержимое брошюр не подключено как каталог MCP.

`host_search_required` содержит лишь предложение запроса: агент обязан выполнить его веб-инструментом, прежде чем предъявлять найденные проекты. Доступность зависит от момента, среды и конкретного URL; результаты поиска хоста могут отличаться от прямого HTTP.

## Воспроизведение

- Автономные тесты: `python -m unittest -v test_server test_visualization test_sources`.
- Живая проверка карточек и изображений через протокол: `python live_sources.py`.
- Дополнительная проверка OfficeNext: `python test_server.py --live`.

Живые тесты выполняются вручную, не в CI. Они не сохраняют исходные страницы и изображения и возвращают ненулевой код при сбое проверяемой операции. HTTP 200 сам по себе не считается успехом: нужны распознанная карточка, корректная принадлежность галереи и декодируемые пиксели.

## Передача изображений через MCP

В межисточниковом прогоне подтверждено декодирование JPEG в памяти клиента: ArchDaily — 528×352, FRAME — 1600×1067, Architizer Journal — 1500×1000, A+Awards — 1600×1426, WAF — 1024×1024. Проверен общий поиск с результатами нескольких площадок и отдельными подсказками для хоста. Первое изображение OfficeNext завершилось тайм-аутом, поэтому общий live-прогон вернул код 1; все проверки новых адаптеров прошли. Это не скрыто и не объявляется полностью зелёным live-прогоном.
